**PicoResize** 是一款專為 Windows 設計的高效能批次處理工具，支援圖片（JPG、PNG、WebP、BMP、TIFF）與 PDF 文件的拖放匯入。在 100% 安全的本機離線環境下，自動完成**白邊裁切**、**方向智慧長寬比縮放**以及**目標檔案大小（MB）壓縮**。

---

## 🌟 主要功能特色

1. **自動邊界白邊裁切（Auto Trim）**
   - 自動偵測並裁切照片、掃描影像與 PDF 頁面外圍不必要的空白白邊。
2. **方向感知智慧縮放（維持長寬比）**
   - 根據使用者輸入的尺寸規格（例如 `[ 640 ] × [ 480 ]`）進行適應：
     - **橫向圖片（寬 ≥ 高）**：維持長寬比自適應填入 寬 × 高 = `640 × 480`。
     - **直向圖片（高 > 寬）**：自動判斷並反轉，維持長寬比填入 高 × 寬 = `640 × 480`（寬 480 × 高 640）。
3. **目標容量（MB）自動二分搜尋壓縮**
   - 透過二分搜尋演算法自動調整最佳壓縮比，確保檔案大小壓制在指定門檻（如 `0.5` MB）以下且畫質不失真。
4. **重複檔名自動流水號**
   - 若儲存目錄已存在相同檔名，自動標註 `(2)`、`(3)` 等序號，避免任何誤覆蓋。
5. **PDF 與圖片混合批次處理**
   - 支援將多種格式的圖片與 PDF（第 1 頁以 300 DPI 超清晰轉化）拖入同一列表統一處置。
6. **極致輕量記憶體佔用（穩定 10–20 MB）**
   - 結合 Win32 工作集釋放、UI 虛擬化與閒置資源自動回收，維持約 10 MB 的極簡記憶體負擔。
7. **完整 8 國語言介面支援**
   - 🌐 支援日語、英語、簡體中文、繁體中文、韓語、西班牙語、德語、法語，即時切換且設定自動持久化。
8. **Velopack 雲端自動更新**
   - 整合 Velopack 差分更新，一鍵偵測並下載最新版本。

## 🖥️ 系統需求
- **作業系統**：Windows 10（版本 2004 以上）/ Windows 11（x64）
- **執行環境**：全獨立包裝（無需額外安裝 .NET Runtime）

---

## 🚀 使用指南
1. 設定上方欄位的「長寬比例（寬 × 高）」、「目標大小（MB）」與「輸出格式（JPEG / PNG / WebP）」。
2. 將圖片或 PDF 拖曳至中央區塊（或點擊「新增檔案」選取）。
3. 點選「🚀 轉換並儲存」並指定儲存資料夾。
4. 處理完畢後將顯示完成通知，可一鍵開啟目的資料夾。
