**PicoResize** 是一款高性能 Windows 桌面端工具，支持通过拖放批量导入图片（JPG、PNG、WebP、BMP、TIFF）和 PDF 文档。在 100% 安全的本地离线环境中，快速执行**自动白边去除**、**自适应横纵比调整**及**目标文件大小（MB）压缩**。

---

## 🌟 核心功能特性

1. **自动白边剪裁（Auto Trim）**
   - 自动检测并剔除照片、扫描文档和 PDF 页面四周多余的白色空白边框。
2. **方向智能识别调整（保持宽高比）**
   - 根据用户输入的尺寸框（例如 `[ 640 ] × [ 480 ]`）智能适配：
     - **横向图片（宽 ≥ 高）**：保持比例自适应填入 宽 × 高 = `640 × 480` 的边框中。
     - **纵向图片（高 > 宽）**：自动旋转方向，保持比例自适应填入 高 × 宽 = `640 × 480`（宽 480 × 高 640）的边框中。
3. **目标文件大小（MB）自动压缩**
   - 基于二分查找算法自动调节压缩率，确保文件控制在指定容量（如 `0.5` MB）以内，同时尽可能保持最高画质。
4. **同名文件自动智能编号**
   - 目标文件夹若存在同名文件，自动追加 `(2)`、`(3)` 等编号，杜绝意外覆盖。
5. **PDF 与图片无缝批量导入**
   - 支持将多张图片与 PDF 文档（第 1 页以 300 DPI 高清栅格化）混合拖入同一任务列表批量处理。
6. **极简内存占用（稳定维持在 10–20 MB）**
   - 运用 Win32 工作集修剪技术、UI 虚拟化与空闲期内存深度回收，保持仅约 10 MB 的极低内存运行。
7. **完整 8 种语言本地化**
   - 🌐 原生支持日语、英语、简体中文、繁体中文、韩语、西班牙语、德语、法语，实时一键切换并自动保存偏好。
8. **Velopack 自动更新**
   - 内置 Velopack 静默增量更新，一键获取最新版本。

## 🖥️ 运行环境要求
- **操作系统**：Windows 10（版本 2004 或更高）/ Windows 11（x64）
- **运行时**：完全独立打包（无需额外安装 .NET 运行时）

---

## 🚀 快速上手
1. 在顶部面板设定「长宽比尺寸（宽 × 高）」、「目标容量（MB）」以及「输出格式（JPEG / PNG / WebP）」。
2. 将待处理的图片或 PDF 文件拖放到中央区域（或点击「添加文件」按钮选择）。
3. 点击「🚀 转换并保存」按钮，指定输出目标文件夹。
4. 处理完成后将弹出提示，支持一键直接打开目标文件夹。
