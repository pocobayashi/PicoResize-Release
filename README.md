**PicoResize** は、画像（JPG / PNG / WebP / BMP / TIFF）および PDF ドキュメントをドラッグ＆ドロップで一括読み込みし、**白余白の自動除去**・**縦横比の自動判定フィット**・**目標容量（MB）への圧縮**を安全な完全ローカル環境で高速に実行する Windows デスクトップアプリケーションです。

---

## 🌟 主な機能と特長

1. **白余白の自動除去（Auto Trim）**
   - 写真やスキャン画像、PDF用紙の周囲にある不要な白余白を自動検知して完全に切り落とします。
2. **縦横自動判定リサイズ（アスペクト比維持）**
   - ユーザーが入力した `[ 640 ] × [ 480 ]` などの枠に対し：
     - **横長画像（幅 ≧ 高さ）**: 横 × 縦 = `640 × 480` の枠に縦横比を維持してフィット
     - **縦長画像（高さ ＞ 幅）**: 縦 × 横 = `640 × 480`（幅480 × 縦640）の枠に縦横比を維持して自動反転フィット
3. **目標ファイルサイズ（MB）への自動圧縮**
   - 指定した容量（例: `0.5` MB）以下になるよう、二分探索アルゴリズムで画質劣化を最小限に抑えながら自動調整します。
4. **同名ファイルの自動連番付与**
   - 保存先フォルダーに同名ファイルが既に存在する場合、上書きせず自動的に `(2)`, `(3)` などの連番を付与して安全に保存します。
5. **PDF & 画像のシームレス一括受付**
   - PDF（第1ページ目を高精細ラスタライズ）と各種画像ファイルを同一リストでまとめてドラッグ＆ドロップ可能です。
6. **極限メモリ削減（10〜20MB台を常時キープ）**
   - 空きメモリのOSへの即時返却（Working Set Trimming）、UI仮想化、アイドル時自動回収により、常時 10MB 前後の超軽量メモリフットプリントで軽快に動作します。
7. **8言語完全ローカライズ対応**
   - 🌐 日本語、English、简体中文、繁體中文、한국어、Español、Deutsch、Français の8言語に対応。ワンクリックでリアルタイムにUI言語が切り替わり、設定は自動保持されます。
8. **Velopack による自動アップデート**
   - 更新確認ボタンを押すだけで最新バージョンを自動取得し、シームレスに更新できます。

## 🖥️ 動作環境
- **OS**: Windows 10 (バージョン 2004 以降) / Windows 11 (x64)
- **ランタイム**: 完全セルフコンテインド（追加の .NET ランタイムインストールは不要）

---

## 🚀 使い方
1. 設定欄で「縦横比（幅 × 高さ）」「目標容量（MB）」「出力形式（JPEG / PNG / WebP）」を指定します。
2. 画像または PDF ファイルを画面中央の DD エリアへドラッグ＆ドロップします（または「ファイルを追加」ボタンから選択）。
3. 「🚀 変換して保存」ボタンをクリックし、保存先フォルダーを指定します。
4. 処理が完了すると完了メッセージが表示され、ワンクリックで保存先フォルダーを開くことができます。
