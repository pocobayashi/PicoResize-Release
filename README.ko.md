**PicoResize**는 이미지(JPG, PNG, WebP, BMP, TIFF)와 PDF 문서를 일괄 드래그 앤 드롭하여, 안전한 100% 로컬 오프라인 환경에서 **여백 자동 제거**, **종횡비 자동 맞춤 리사이징**, **목표 용량(MB) 자동 압축**을 초고속으로 수행하는 Windows 데스크톱 애플리케이션입니다.

---

## 🌟 주요 기능

1. **흰색 여백 자동 잘라내기 (Auto Trim)**
   - 사진, 스캔 문서, PDF 페이지 주변의 불필요한 흰색 테두리를 자동으로 인식하여 깔끔하게 제거합니다.
2. **방향 인식 스마트 리사이징 (가로세로 비율 유지)**
   - 사용자가 입력한 치수 규격(예: `[ 640 ] × [ 480 ]`)에 맞춰 지능적으로 처리합니다:
     - **가로 이미지 (너비 ≥ 높이)**: 가로 × 세로 = `640 × 480` 비율 유지 맞춤
     - **세로 이미지 (높이 > 너비)**: 세로 × 가로 = `640 × 480` (너비 480 × 높이 640)으로 자동 회전 맞춤
3. **목표 파일 크기(MB) 자동 압축**
   - 이진 탐색 알고리즘을 통해 화질 저하를 최소화하면서 설정한 목표 용량(예: `0.5` MB) 이하로 품질을 정밀하게 자동 조절합니다.
4. **동일 파일명 자동 번호 부여**
   - 저장 폴더에 동일한 파일명이 이미 존재하는 경우 덮어쓰지 않고 `(2)`, `(3)` 형식의 번호를 자동으로 추가합니다.
5. **PDF 및 이미지 통합 일괄 처리**
   - PDF(1페이지를 300 DPI 고해상도로 래스터화)와 각종 이미지 파일을 동일한 목록에 한 번에 등록하여 처리할 수 있습니다.
6. **초경량 메모리 점유율 (10–20 MB 대 상시 유지)**
   - Win32 워킹셋 트리밍, UI 가상화, 유휴 시간 자동 메모리 회수 기술을 적용하여 약 10 MB의 극히 작은 메모리 사용량을 유지합니다.
7. **8개 국어 완벽 다국어 지원**
   - 🌐 한국어, 일본어, 영어, 중국어 간체, 중국어 번체, 스페인어, 독일어, 프랑스어를 지원하며 실시간 언어 전환 및 자동 저장됩니다.
8. **Velopack 자동 업데이트**
   - Velopack 기반의 원클릭 최신 버전 확인 및 증분 업데이트를 지원합니다.

## 🖥️ 시스템 요구 사항
- **운영체제**: Windows 10 (버전 2004 이상) / Windows 11 (x64)
- **런타임**: 자체 포함(Self-contained, 별도 .NET 런타임 설치 불필요)

---

## 🚀 사용 방법
1. 상단 설정 바에서 가로세로 규격(`너비 × 높이`), 목표 크기(MB), 출력 포맷(`JPEG / PNG / WebP`)을 지정합니다.
2. 처리할 이미지나 PDF 파일을 중앙 영역으로 드래그 앤 드롭합니다(또는 "파일 추가" 버튼 사용).
3. "🚀 변환 및 저장" 버튼을 클릭하고 대상 폴더를 선택합니다.
4. 작업이 완료되면 결과 안내창이 뜨며 클릭 한 번으로 대상 폴더를 열 수 있습니다.
